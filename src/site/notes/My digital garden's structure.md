# Tags 🏷️
The ==statuses== of these notes are **draft**, **edit**, and **published**. Some people use a seed metaphor for this (seed, sprout, evergreen respectively), but I wanted something I wouldn't have to think about. There's also **archived** for older or less relevant notes.

This is the only thing I use Obsidian tags for. My notes have empty notes that I call tags, which you can see on my [[4 - Indexes/Sitemap\|Sitemap]] and below in the [[My digital garden's structure#File structure 📂\|#File structure 📂]].

# File structure 📂
Here's a quick rundown of the file structure I [copied from Odysseas](https://www.youtube.com/watch?v=hSTy_BInQs8&t=444s):

| Folder          | Purpose                                                                                          |
| --------------- | ------------------------------------------------------------------------------------------------ |
| Rough Notes     | Things I don't want to forget or want to share.                                                  |
| Source Material | Insights from anything I consume *in context*, sorted by medium. Unsorted notes are in progress. |
| Tags            | Tags (empty notes with backlinks to actual notes).                                               |
| Indexes         | Indexes created from tag notes.                                                                  |
| Templates       | Templates for pages, published for reference.                                                    |
| Main Notes      | Default location for all unprocessed fleeting notes and web clippings.                           |
Any note outside of this structure is a "meta" page giving the site more context, like this page or my [[Changelog\|Changelog]].

# Note templates 📃
>[!tip]+ My hotkey to insert a template is `Ctrl + Q`.
>If you want a template hotkey in Obsidian, you can change it in Settings > Hotkeys (under Options).

The [[5 - Templates/Topic note\|template for my main notes]] is based off [Odysseas](https://www.youtube.com/watch?v=hSTy_BInQs8&t=444s)' and modified to fit a look inspired by [Hiran Venugopalan's Working Notes](https://hiran.in/). The [[5 - Templates/Fiction source note\|Fiction source note]] and [[5 - Templates/Nonfiction source note\|Nonfiction source note]] templates are pretty much the same as [Carolyn Yoo's](https://garden.carolynyoo.com/Source-Notes/Reading-Note-Templates/Nonfiction-Template).
