# Be comfortable with forgetting
[What we write down is what we remember.](https://app.capacities.io/9773b04e-f1b9-4769-b662-975f16fbcdeb/49824d07-ad35-41da-be0d-00544bc77769) Not everything mentioned in a class is important, not everything needs to be remembered.
