# Zettelkasten
organization method for a personal [[6 - Main Notes/knowledge management\|knowledge management]] system that centers thinking and writing.

input resonant info -> organize, identify, categorize -> output something you created.

created by Niklas Luhmann, a German sociologist.

Zettelkasten practitioners recommend creating ***[[6 - Main Notes/atomic note\|atomic note]]s*** so that you can connect them with other notes and build new ideas.
