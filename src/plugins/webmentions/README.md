# Webmentions

Shows likes, reposts, and replies from around the web under your notes, via webmention.io.

A plugin for [Digital Garden](https://github.com/oleeskild/digitalgarden) sites.

## Install

Paste this repo's URL into **Settings → Digital Garden → Plugins → Install from GitHub** in Obsidian, or copy this folder into `src/plugins/webmentions/` in your garden repo.

## Settings

- **Domain** — Your garden's domain as registered with webmention.io, e.g. garden.example.com.
- **API token** — Your webmention.io API token (read-only; found on your webmention.io dashboard).
