# Giscus Comments

GitHub-Discussions-backed comments under every note, powered by giscus.app.

A plugin for [Digital Garden](https://github.com/oleeskild/digitalgarden) sites.

## Install

Paste this repo's URL into **Settings → Digital Garden → Plugins → Install from GitHub** in Obsidian, or copy this folder into `src/plugins/giscus-comments/` in your garden repo.

## Settings

- **Repository** — The public GitHub repo with Discussions enabled, as owner/name. Set it up at giscus.app.
- **Repository ID** — From giscus.app.
- **Discussion category**
- **Category ID** — From giscus.app.
- **Theme**
- **Show on all notes** — Turn off a single note with comments: false in its frontmatter.
