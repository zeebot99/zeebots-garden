# Note Age Banner

Warns readers when a note hasn't been tended for a while.

A plugin for [Digital Garden](https://github.com/oleeskild/digitalgarden) sites.

## Install

Paste this repo's URL into **Settings → Digital Garden → Plugins → Install from GitHub** in Obsidian, or copy this folder into `src/plugins/note-age-banner/` in your garden repo.

## Settings

- **Age threshold (days)** — Show the banner on notes not updated for this many days.
- **Banner message**
