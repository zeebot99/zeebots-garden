# Random Note Button

A dice button in the navigation that jumps to a random note.

A plugin for [Digital Garden](https://github.com/oleeskild/digitalgarden) sites.

## Install

Paste this repo's URL into **Settings → Digital Garden → Plugins → Install from GitHub** in Obsidian, or copy this folder into `src/plugins/random-note-button/` in your garden repo.
